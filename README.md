# Mi primer repositorio

Repositorio de práctica del **Taller de Programación II** para aprender a usar GitHub.

## Contenido

| Archivo | Para qué sirve |
|---|---|
| `hola.py` | Programa en Python que saluda por nombre |
| `index.html` | Página web publicada con GitHub Pages |
| `apuntes.md` | Resumen de los comandos de Git |

## Cómo ejecutar el programa

```bash
python hola.py
```
